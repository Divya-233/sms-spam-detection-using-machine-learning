SMS Spam Detection Using Machine Learning

Project Overview

This project uses Machine Learning to classify SMS messages as Spam or Ham (Not Spam).

Objectives

- Detect spam messages automatically.
- Classify messages using Machine Learning.
- Understand text classification.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

Project File

- sms_spam_detection.ipynb – Jupyter Notebook containing the project code
Project Workflow

1. Import libraries.
2. Load the dataset.
3. Clean and preprocess text.
4. Convert text into numerical features.
5. Train a Machine Learning model.
6. Evaluate model performance.
7. Predict whether messages are Spam or Ham.
